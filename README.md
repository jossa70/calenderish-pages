# calenderish-pages

The home page and privacy policy for Calenderish. Google's OAuth consent screen links to both.

They are published with GitHub Pages from `main` on `https://calenderish.pappaklanen.se`, and a push to `main` publishes the change. The `CNAME` file holds the custom domain, so leave it in place. The app itself runs on `https://calenderish.se`.
